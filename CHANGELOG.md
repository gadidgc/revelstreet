# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0.0] - 2026-04-26

### Added
- New two-number calculator application with beautiful animations
- Glassmorphism UI design with backdrop blur and gradient background
- Real-time calculation on input change with smooth fade-in and scale animations
- Responsive design supporting all screen sizes
- Single HTML file with vanilla JavaScript and CSS (no build step, no dependencies)

### Design Features
- Minimalist aesthetic focused on radical simplicity
- Smooth 0.6s cubic-bezier animations for result display
- Mobile-responsive layout with modern design patterns
- Accessibility-first HTML structure with proper labels

## [0.1.0.0] - 2026-04-26

### Added
- Project initialized with basic structure
